# OMNA — Claude Code plugins

Marketplace de plugins de Claude Code de OMNA (descentralizado).

## Instalar
```
export GITHUB_TOKEN=ghp_…        # para auto-updates de un repo privado
/plugin marketplace add rasputin28/omna-claude-plugins
/plugin install omna-brain@omna
```
Necesitas una API-key de OMNA en `OMNA_API_KEY` (ver el README del plugin).
